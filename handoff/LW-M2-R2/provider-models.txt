GEMINI (adapter implemented AND live-tested; gemini-3.6-flash quota-blocked mid-campaign)
---------------------------------------------------------------------------
Source: https://ai.google.dev/gemini-api/docs/models
        https://ai.google.dev/gemini-api/docs/pricing
        https://ai.google.dev/api/generate-content
        https://ai.google.dev/gemini-api/docs/structured-output

  Quality tier ("Gemini 3.6 Flash")
    API model id:        gemini-3.6-flash
    Context window:      1,000,000 tokens
    Pricing:              $1.50 / 1M input tokens, $7.50 / 1M output tokens
    Structured output:    yes (generationConfig.responseSchema + responseMimeType=application/json)

  Cheap/high-volume tier ("Gemini 3.5 Flash Lite")
    API model id:        gemini-3.5-flash-lite
    Context window:      1,000,000 tokens
    Pricing:              $0.30 / 1M input tokens, $2.50 / 1M output tokens
    Structured output:    yes (same mechanism)

  Endpoint:   POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent
  Auth:       x-goog-api-key header (NOT the legacy ?key= query parameter — avoids the secret
              appearing in URLs/server access logs)
  Usage:      usageMetadata.promptTokenCount / usageMetadata.candidatesTokenCount
  Rate limits: usage-tier-dependent, viewable only in a signed-in AI Studio console
              (https://aistudio.google.com/rate-limit) — not independently re-verified in this
              task; no live call was made regardless, so no quota was at risk.

DEEPSEEK (adapter implemented AND live-tested; both tiers, 23/24 pass post-fix)
-----------------------------------------------------------------------------------------
Source: https://api-docs.deepseek.com/quick_start/pricing
        https://api-docs.deepseek.com/api/create-chat-completion
        cross-checked against independent web search

  NOTE: legacy names deepseek-chat / deepseek-reasoner were RETIRED 2026-07-24. Do not use them.

  Recommended/strongest general-text candidate
    API model id:        deepseek-v4-pro
    Pricing:              $0.435 / 1M input tokens, $0.87 / 1M output tokens

  Cheapest/fastest candidate
    API model id:        deepseek-v4-flash
    Context window:      1,000,000 tokens (up to 384K output tokens)
    Pricing:              $0.14 / 1M input tokens (cache miss), $0.0028 / 1M (cache hit, 98% off),
                          $0.28 / 1M output tokens
    Supports both non-thinking and thinking mode under the same model id (request parameter,
    not a separate model id).

  Structured output:    response_format={"type":"json_object"} guarantees valid JSON syntax only —
                        does NOT enforce a specific shape the way Gemini's responseSchema or
                        Anthropic's tool-forced schema does. A real adapter would need to embed the
                        target schema into the prompt text itself. This is a genuine capability
                        gap versus the other two candidates, not just smaller scope.
  Usage:                usage.prompt_tokens / usage.completion_tokens
                        (+ prompt_cache_hit_tokens / prompt_cache_miss_tokens for cache-aware cost)

PRODUCTION_POLICY_CONSTRAINT (see docs/NARRATIVE_MODEL_EVALUATION.md §9 for full detail)
------------------------------------------------------------------------------------------
Both Gemini's and DeepSeek's current API terms require the calling service to be 18+ /
not directed at an under-18 audience. Lorewish is a 13+ mainstream product (PRODUCT_VISION.md,
MVP_SPEC.md), explicitly not an 18+ platform. This conflict was NOT resolved automatically —
recorded for owner/legal review before either provider is treated as production-eligible.
Anthropic's terms present a materially different posture (see NARRATIVE_MODEL_EVALUATION.md §9)
but this is prose analysis of public terms pages, not a legal opinion.
