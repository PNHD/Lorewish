    feat: LW-M2-R1 real interactive story engine vertical slice
    
    Adds the first real, persistent, AI-generated interactive story loop on top
    of the M1 authoring schema: player_runs/run_branches/scenes/turns/canon_facts
    runtime schema with branch-safe scene ordering and canon isolation, a
    provider-agnostic NarrativeProvider gateway (fake deterministic provider +
    an Anthropic adapter, unverified against live network — no credential
    configured), the Continuous Play Contract state machine (precheck -> generate
    -> validate -> commit, one repair max, idempotent turn_id, atomic commit via
    SECURITY DEFINER RPCs so clients never write Scene/CanonFact directly), a
    deterministic narrative quality gate, a bounded context assembler, a Narrative
    Golden Set + dev-only bakeoff harness, a /play/[runId] EN+VI reading UI reusing
    the M1 Scene Readability Contract components, and 35 unit tests plus 20 live
    adversarial probes against the deployed lorewish-dev schema and Edge Functions.
    
    CI: split native-evidence jobs to only run on native-relevant path changes or
    manual dispatch, added the deterministic-provider test suite to the fast
    web/JS job, raised the iOS timeout to 40 minutes.
    
    No AI provider credential exists in this environment; real generation is not
    demonstrated. See docs/NARRATIVE_MODEL_EVALUATION.md.
